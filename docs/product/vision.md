# Career OS — Product Vision

## The Problem

Software engineers preparing for interviews or upskilling face severe cognitive fragmentation:
- Curricula and roadmaps are scattered across Google Sheets, PDFs, Notion pages, and bookmark lists.
- Progress tracking is split between LeetCode, GitHub, spreadsheets, and sticky notes.
- Users waste hours manually formatting and organizing problem lists instead of solving problems.
- Existing tools are either bloated generic dashboards or bare-bones static lists.

## The Vision

**Career OS** is the personal Career Operating System for engineers. It unifies roadmap ingestion, study schedules, problem-solving progress, and technical mastery into a focused workspace.

### Core Tenets

1. **Effortless Ingestion**: Paste any URL (Google Doc, Google Sheet, DSA blog) or upload a PDF, and Career OS instantly creates an interactive, structured curriculum.
2. **Linear-Grade Craftsmanship**: Ultra-fast, keyboard-driven, minimalist, and visually refined. No flashy gimmickry, no neon clutter, no generic admin widgets.
3. **Cross-Curriculum Mastery**: Problems are canonically mapped so solving "Two Sum" in Blind 75 automatically reflects in Striver's SDE Sheet and NeetCode 150.
4. **Connected Ecosystem**: Unobtrusive background sync with developer workflows (GitHub commits, LeetCode submissions, spaced repetition review queues).
